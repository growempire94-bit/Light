# Свет 💡: сигнал, когда дали свет

Приложение для iPhone. Оно записывает в журнал, когда свет в доме пропадает и когда появляется, а при появлении света включает **громкую сирену**. Свет определяется по домашнему Wi‑Fi.

## Как это работает

1. Роутер питается от сети. Свет пропал → роутер выключился → домашний Wi‑Fi исчез → в журнал попадает «Свет пропал».
2. Свет дали → роутер загрузился → iPhone **сам** подключается к знакомой сети, даже если включён мобильный интернет: iOS всегда предпочитает известный Wi‑Fi.
3. Приложение следит именно за интерфейсом Wi‑Fi, а не за интернетом вообще, поэтому мобильные данные не мешают. Как только домашняя сеть появилась, оно делает запись «Свет появился (не было 2 ч 15 мин)», включает сирену на максимальной громкости (даже в беззвучном режиме), вибрацию и уведомление.

Короткие обрывы Wi‑Fi, например перезагрузка роутера, игнорируются. Порог по умолчанию 30 сек, его можно изменить в настройках.

### Возможности
- Статус «Свет есть / Света нет» и сколько времени длится текущее состояние.
- Журнал всех включений и отключений, статистика за день, экспорт текста (для заметок или Telegram).
- Домашняя сеть по имени (SSID): тогда кафе или чужой Wi‑Fi не вызовут ложную тревогу.
- Настройки: длительность сирены, максимальная громкость, вибрация, уведомление о пропадании.
- Действие «Проверить свет» для приложения «Команды». Это подстраховка на случай, если iOS выгрузит приложение.

### Важно
- **Не закрывайте приложение смахиванием** в переключателе приложений. Просто сверните его: оно работает в фоне.
- При первом запуске разрешите **уведомления** и **геопозицию**, причём точную. iOS показывает имя Wi‑Fi только приложениям с доступом к геопозиции. Само местоположение не используется.
- Если подключены Bluetooth‑наушники или колонка, сирена играет туда.
- Подстраховка: «Команды» → «Автоматизация» → «+» → «Wi‑Fi» → выберите домашнюю сеть → «Запускать сразу» → действие **«Проверить свет»**. Можно добавить ещё «Установить громкость 100%».

## TestFlight (сборка в облаке, Mac не нужен)

Сборкой и загрузкой занимается GitHub Actions (`.github/workflows/ios.yml`). Нужен **платный Apple Developer Program** ($99 в год), без него TestFlight недоступен.

Что сделать один раз:

1. **Идентификатор приложения.** [developer.apple.com → Identifiers](https://developer.apple.com/account/resources/identifiers/list) → «+» → App IDs → App. Bundle ID: `com.svetlo.lightwatch` (или свой, см. п. 5). В списке Capabilities отметьте **Access Wi‑Fi Information**.
2. **Приложение в App Store Connect.** [appstoreconnect.apple.com](https://appstoreconnect.apple.com) → «Приложения» → «+» → «Новое приложение» → iOS, имя «Свет» (если имя занято, подойдёт любое), Bundle ID из п. 1, SKU любой.
3. **API‑ключ.** App Store Connect → «Пользователи и доступ» → «Интеграции» → «Ключи App Store Connect API» → «+». Роль **Admin**: она нужна, чтобы облако само создало сертификат подписи. Скачайте файл `AuthKey_XXXX.p8`, это можно сделать только один раз. Запишите **Key ID** и **Issuer ID**.
4. **Секреты в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   | Секрет | Значение |
   |---|---|
   | `APPLE_TEAM_ID` | Team ID (developer.apple.com → Membership) |
   | `ASC_KEY_ID` | Key ID из п. 3 |
   | `ASC_ISSUER_ID` | Issuer ID из п. 3 |
   | `ASC_KEY_P8` | всё содержимое файла `.p8`, включая строки `-----BEGIN/END PRIVATE KEY-----` |
5. (Необязательно) Свой Bundle ID: вкладка **Variables** → `BUNDLE_ID`.
6. Actions → «iOS build & TestFlight» → **Run workflow**. Через 5–30 минут после загрузки сборка появится в TestFlight. Добавьте себя во внутренние тестировщики, установите приложение TestFlight на iPhone и поставьте «Свет».

Каждый push собирает новую сборку, номер сборки растёт автоматически. Если секретов нет, job TestFlight просто пропускается, а job `build` всё равно собирает неподписанный `Light-unsigned.ipa` (артефакт запуска). Его можно поставить через Sideloadly или AltStore с бесплатным Apple ID.

## Сборка через Xcode (если есть Mac)

Откройте `Light.xcodeproj` (Xcode 16 или новее) → target **Light** → Signing & Capabilities → выберите свою команду → запустите на iPhone.
Если у вас бесплатный Apple ID и Xcode ругается на «Access WiFi Information», удалите эту capability. Приложение будет работать, но имя сети знать не будет: тогда любая Wi‑Fi сеть считается домашней.

## Структура
```
Light/
  PowerMonitor.swift     — слежение за Wi‑Fi и логика «свет есть / нет»
  AudioManager.swift     — фоновый режим и сирена
  ToneGenerator.swift    — генерация звука сирены (без аудиофайлов)
  VolumeController.swift — громкость на максимум
  EventLog.swift         — журнал событий
  WiFiInfo.swift         — имя сети и разрешение геопозиции
  CheckLightIntent.swift — действие для «Команд»
  ContentView.swift      — интерфейс
Config/                  — Info.plist и entitlements
```
